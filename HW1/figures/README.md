# Grafice HW1

Imaginile sunt grupate după experiment; CSV-urile, jurnalele și metadatele rămân în directoarele de rezultate din `HW1`.

| Director | Conținut |
| --- | --- |
| [benchmark/](benchmark/) | Suita generală: timp, speedup, eficiență, rezoluții și verificare vizuală |
| [benchmark_two_machines/](benchmark_two_machines/) | Studii pe două calculatoare, separate în `1.5MP`, `4MP`, `8MP`, `64MP` și `combined` |
| [benchmark_small_two_machines/](benchmark_small_two_machines/) | Experimentele inițiale cu imagini mici pe două calculatoare |
| [benchmark_small_two_machines_blur_hp_local/](benchmark_small_two_machines_blur_hp_local/) | Blur pe imagini mici, local pe HP-Laptop |
| [benchmark_small_two_machines_blur_victus/](benchmark_small_two_machines_blur_victus/) | Blur pe imagini mici, pe Victus |
| [partition_strategies/](partition_strategies/) | Ilustrații SVG și vizualizarea interactivă a partiționării |

În studiile pe două calculatoare, `execution_time_*` arată timpul total, `speedup_*` accelerarea față de referința secvențială, iar `partition_strategies_*` compară strategiile.
