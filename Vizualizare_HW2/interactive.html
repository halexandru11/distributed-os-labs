Execution & simulation

A collapsed group uses one team. Nested levels multiply the requested team sizes. A team of one does not consume an active level.

The dispatch seed only breaks ties in the teaching simulation. It is separate from the input-matrix seed and is not an OpenMP runtime option.

Numbers & memory

Our C implementation uses uint64; the homework allows choosing an integer type. In that mode, input integers are reduced modulo 2⁶⁴. Layout changes memory positions, not the mathematical matrix or work ownership.
